# 地层矩阵编辑台（Harris Matrix Workbench）

纯浏览器运行的考古地层矩阵编辑工具：Vue 3 + TypeScript，Graphology 管理有向关系，
Cytoscape.js 绘制矩阵，Dexie(IndexedDB) 本地持久化。**不发生任何网络上传**，现场资料只存于本机浏览器。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 产出静态文件到 dist/，可离线部署
npm test         # 解释方案分支验收测试（Node + fake-indexeddb，73 项检查）
npm run typecheck
```

## 数据模型要点

- **身份与位置分离**：层位（`units`）与画布坐标（`positions`）分表存储，拖动/自动排布不影响地层身份。
- **三类记录分开保存**：原始观察与推断（`relations.source`）、被撤销判断（`retractions` 表，含快照与理由）。
- **解释方案分支**：关系（观察/推断/同期）按方案（`schemes` 表）分支，层位、证据、画布位置为各方案共享。
  从当前方案派生命名方案时完整复制关系集（含已撤回判断与撤销记录），此后各方案增删互不影响；
  来源方案仅作溯源引用（`sourceSchemeId` + 名称快照），删除来源不破坏已派生方案；
  当前方案选择持久化于 `meta` 表，刷新后恢复。
- **语义对比**：任选两个方案对比——直接边差异按 (起点,终点,种类) 语义键匹配（与关系 id 无关），
  并比较活跃“早于”关系的传递闭包，标出因闭包变化而新增/失效的**纯传递结论**；
  直接边有差异但闭包一致（如增删冗余边）时明确提示先后结论一致，不误报。
  对比视图只读，点击差异项仅在画布定位相关层位，不改写任一方案。
- **同期关联不是有向边**：`contemporary` 关系只存档、以紫色虚线显示，绝不进入 Graphology 有向图与偏序闭包。
- **成环检测**：新增“早于”关系时，若 `to→…→from` 已有路径则构成环，对话框给出完整环路径，
  记录员可取消或保留为矛盾记录（红色虚线，不删除任何原始观察）。成环检测基于当前方案边集，
  矛盾标记只落在本方案的记录上。
- **矩阵简化只隐藏**：简化视图通过传递约简隐藏冗余边（如 1007→1003 被 1007→1006→1005→1003 蕴含），原始记录全部保留。
- **批次撤销**：每次操作登记为含逆变更的批次（`batches` 表），撤销整批回滚——关系、证据引用、撤销记录一起恢复。
- **导出/导入**：JSON 文件携带方案表、当前方案与偏序闭包（可达对列表），导入后重算比对，偏序不一致会明确告警。
  旧版（v1，无方案表）工程文件与旧版 IndexedDB 数据首次加载时自动无损迁移为「默认方案」，原关系与撤回记录全部保留。

## 示例工程

「载入示例」包含：基槽/灰坑两处**切割事件**（切割晚于被切层、填土晚于切割）、
**孤立层位** 1018（紫色虚线框）、1012 与 1015 的**同期关联**、
记录员乙与剖面观察**互相矛盾的记录**（1009↔1012 成环标红）、以及一条**已撤销的推断**。

## 目录

```
src/graph.ts    Graphology 封装：成环路径、传递约简、偏序闭包、分层排布
src/compare.ts  方案语义对比：直接边差异 + 传递闭包差异（纯传递结论标注）
src/store.ts    状态与业务：方案派生/切换/删除、批次撤销、导入导出、偏序校验
src/db.ts       Dexie/IndexedDB 八张表（v1→v2 自动迁移为默认方案）
src/sample.ts   示例工程
src/components/MatrixCanvas.vue  Cytoscape 画布
src/components/ComparePanel.vue  方案语义对比面板（只读，点击定位层位）
test/acceptance.ts  解释方案分支验收测试
```
